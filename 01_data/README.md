# ELSA Datasets

This project uses longitudinal data from the English Longitudinal Study of Ageing (ELSA), obtained through the UK Data Service.

## Datasets Used

- ELSA Wave 7
- ELSA Wave 8
- ELSA Waves 7 and 8, Institute for Fiscal Studies (IFS) derived variables

These datasets supported the development and evaluation of machine learning models predicting incident depression among older adults.

## Data Access

The underlying participant-level datasets are not included in this public repository due to data access and licensing restrictions.

Researchers wishing to reproduce the analysis should obtain the relevant datasets through the UK Data Service, subject to the applicable access conditions.

**Official data source:** https://datacatalogue.ukdataservice.ac.uk/studies/study/5050#details

**Study:** English Longitudinal Study of Ageing (ELSA), Study 5050.
